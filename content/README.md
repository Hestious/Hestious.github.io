# Website content

Edit the JSON files in this folder with GitHub's pencil button, then commit to `main`. The website updates after GitHub Pages deploys the commit.

- `profile.json`: your name, affiliation, biography, contact email and links.
- `interests.json`: research-interest sections.
- `publications.json`: publication list; see the repository README for a template.
- `notes.json`: topic descriptions, categories, PDF links and availability.

Lecture-note manuscripts are separate Markdown files in `notes/`. PDF attachments go in `assets/pdfs/`.
