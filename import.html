Connect your publishing account

Only Hestious can publish to this homepage. Connect with a fine-grained GitHub token for this repository. The token stays in this open tab’s memory and is cleared when you disconnect or reload.

Create a publishing token
  1. Open GitHub’s token setup.
  2. Choose Only select repositories, then select Hestious.github.io.
  3. Set repository Contents permission to Read and write, generate the token, and paste it below. Keep the token private.
Connected, but publishing is rejected?

Connecting verifies your account. GitHub checks the token’s permission to write when you publish a change.

  1. Open your fine-grained token settings and select the token you used here.
  2. Check that its resource owner is Hestious, repository access includes Hestious.github.io, and repository Contents permission is Read and write. Save any corrections.
  3. Disconnect here, reconnect with that token, and try publishing again. If the token has expired, create a replacement using the setup above.

If those settings are already correct, use the failed step and GitHub reason shown in the error to diagnose the problem. A request-limit message means you should wait before retrying. Keep your token private.

Prepare your ZIP

  • Download your project’s source ZIP from Overleaf, or zip the project folder.
  • Include the .tex files, bibliography, and figures used by the document.
  • A file named main.tex is preferred. A single document containing \documentclass can also be detected.
  • Keep included files and figures at their original relative paths.

What to expect

The web version supports ordinary text, headings, lists, and mathematical formulas. It is a reading version, so its layout may differ from your compiled PDF.

Supported TikZ and TikZ-CD figures are rendered into the web note. Custom packages and complex commands may still need adjustment. Keep a PDF alongside the web note when exact typesetting matters.

If conversion fails, the previous published website stays available. Open the build status for the error details.
