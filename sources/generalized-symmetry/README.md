# Generalized symmetry: LaTeX source

Upload one LaTeX project ZIP into this folder using **Add file → Upload files**, then choose **Commit changes**. GitHub Actions converts it into a web note and updates the homepage automatically.

To update the note, replace the ZIP using the same filename. Keep exactly one ZIP in this folder. Include the main document, included `.tex` files, bibliography, and figures at their original relative paths.

[Import guide](../README.md) · [Build status](https://github.com/Hestious/Hestious.github.io/actions)

Files uploaded here are public, including their source text and history.
